# ゴルフのオリンピック記録

ホールごとに獲得メダルを選び、獲得点とプレーヤー間の差引点を記録する静的 Web アプリです。スマートフォンでの入力を優先し、2〜4人、9 / 18 ホールに対応します。

## 使い方

1. [オリンピック記録](https://h-yoshinori-tamagami.github.io/olympic/) を開きます。
2. 日付、ホール数、プレーヤー数、名前、ダイヤ設定を入力してラウンドを開始します。
3. ホールごとに各プレーヤーのメダルを選びます。獲得点と差引点は別々に表示されます。
4. ページを閉じても、同じブラウザー内に記録が自動保存されます。履歴からラウンドごとの最後のホールを開き直したり、削除したりできます。

ラウンド記録はブラウザーの `localStorage` に保存され、GitHub やサーバーへ送信されません。ブラウザーのデータ消去や別端末への移行に備え、JSON バックアップを書き出して安全な場所に保管してください。復元すると、現在保存されている全ラウンドがバックアップ内容に置き換わります。置き換え前に確認を表示します。

## ローカルで開く

ビルドやライブラリのインストールは不要です。`rules.json` を相対パスで読み込むため、ローカル HTTP サーバーで開いてください。

```sh
python3 -m http.server 8000
```

ブラウザーで `http://localhost:8000/` を開きます。

## ルール

- 4人：金4点、銀3点、銅2点、鉄1点
- 3人：金4点、銀3点、銅2点
- 2人：金4点、銀3点
- 割り当てた位置から1パットで入ったメダルの点だけを獲得します。獲得なしは0点です。
- ダイヤはグリーン外から直接カップインした場合の5点です。新規ラウンドでは有効にし、ラウンドごとに無効化できます。
- 同じメダルの複数選択を許可します。距離が同じ場合などは組で決めた結果を記録してください。
- 3パット減点、砂イチ・竿イチなどの派生ルール、金額換算は扱いません。

プレーヤー i の差引点は `獲得メダル点_i × (人数 − 1) − 他のプレーヤーの獲得点合計` です。各ホールとラウンド全体の差引点合計は0になります。

標準点数とルール説明は [rules.json](./rules.json) にあります。

## プロジェクト

- `index.html` — 日本語 UI
- `styles.css` — レスポンシブ表示とデザイン token
- `app.js` — 記録、計算、保存、バックアップ / 復元
- `rules.json` — 標準点数とルール説明
- `docs/` — 設計・実装・確認資料
- `.github/workflows/pages.yml` — 静的ファイルを GitHub Pages に公開

外部 CDN、実行時ライブラリ、バックエンド、利用者記録ファイルはありません。公開時にはアプリ本体とロゴだけを Pages に配置し、設計資料や JSON バックアップは配置しません。

## 確認状況

この依頼では test files の追加および test / build コマンドの実行を行いません。ブラウザー操作と GitHub Pages の Actions 実行結果は `TEST_PLAN.md` の状態に記録します。
